# Security And Hardening

Базовые правила безопасности:

- секреты только из переменных окружения;
- никаких токенов, email, паролей и API-ключей в логах;
- проверка авторизации на каждом защищённом endpoint;
- проверка прав администратора на каждом админском endpoint;
- только ORM или параметризованные запросы;
- проверяй внешние URL и загружаемые файлы;
- cookie-авторизация — httpOnly/Secure/SameSite, где применимо;
- для вызовов фронтенда с cookie — `credentials: 'include'`.

Для изменяющих запросов:

- сохраняй проверки Origin;
- не доверяй состоянию, существующему только на фронтенде;
- списывай деньги только на сервере;
- делай повторы идемпотентными, когда речь о деньгах или задачах.

Перед выкатом проверь, что защищённый путь по-прежнему закрыт при сбое (fail closed).
