# Git, деревья и слияние

Основная ветка проекта указана в `project.md`, ниже она называется основной.

- Малую последовательную правку делай прямо в основной ветке. Крупную, долгую или параллельную задачу — в отдельном дереве
  (`.claude/worktrees/`, ветка `claude/<суть>` от локальной основной).
- В основной ветке могут параллельно работать другие сессии. Коммить только свои пути (`git add <пути>`, не `-A` и не `.`), сверяй
  `git diff --cached` перед коммитом, не делай stash, reset и checkout чужих изменений.
- Сливай сам, только если это разрешено в `project.md`: проверь весь diff ветки и отсутствие чужих коммитов, затем в чистой основной ветке
  `git merge --no-edit <ветка>`.
- Конфликт разбирай по смыслу. Решение не очевидно: `git merge --abort` и вопрос владельцу проекта.
- Принятое дерево удаляй. Смонтированное и открытое в других процессах не удаляй: путь залипнет, и следующие команды упадут непонятно.
- Историю основной ветки не переписывай. Force-push только по прямой команде владельца.
- Удаляй строго в пределах задачи: перед удалением посмотри, что именно удаляется.
- Секреты не печатай, не записывай в Git и не перезаписывай при настройке.
