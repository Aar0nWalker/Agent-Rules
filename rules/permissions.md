# Разрешения: деньги, данные, секреты

**Прямое разрешение владельца проекта нужно на:** новый шаг пользователя; изменение привычного поведения; деньги; новую фоновую
работу; разрушительную операцию; чувствительные данные.

**Не ослабляй:** доступ, деньги, данные, жизненный цикл сущностей, существующие тесты и покрытие.

**Платные вызовы:**
- Только по просьбе владельца, в пределах его лимита, под служебным тестовым аккаунтом из `project.md`, без прав администратора.
- Перед платным вызовом в той же сессии проверь, под кем ты вошёл. Не тот аккаунт — останови вызов.
- Без автоматических повторов. Больший расход требует отдельного разрешения.
- Перед дорогим разбором оцени стоимость заранее.

**Секреты:** не печатай, не переноси между инструментами, не записывай в Git и логи. Credentials и cookie — так же.

**Сообщения клиентам** отправляются только после «да» владельца.

**Необратимое и внешнее** (удаление данных, запись в прод, рассылка, публикация): согласовать, показать, что именно будет сделано.
