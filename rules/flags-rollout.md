# Флаги, стенд и прод

Адреса стендов и команды выката — в `project.md`.

- Флаг — только в двух случаях: новый текст промпта или поведение модели (выключатель для отката) и новая функция или шаг
  пользователя до «принимаю» владельца. Флаг по умолчанию выключен.
- Остальное (исправления багов, механика, интерфейс, деньги) — без флага: ревью, проверка на стенде, выкат. Откат — `git revert` и
  выкат.
- Флаг доказан, когда тесты затронутых модулей зелёные, итоговый промпт и запрос без отправки проверены (флаг выкл. и вкл.),
  соседний путь цел, есть ревью и успешный выкат стенда с включённым флагом. Включён на стенде — ещё не доказан.
- Доказанный флаг переводится в постоянный код и снимается вместе со старой веткой в той же пачке. Накопленные флаги
  разбираются пачками: включённые везде — в постоянный код, выключенные везде — удалить код.
- Прод — по правилу из `project.md` (кто катит и как часто); по умолчанию только по команде владельца. Всегда по «да» владельца —
  то, что трогает деньги, сообщения клиентам, удаление данных или добавляет шаг пользователю.
- Прод и стенд исполняют один код. Ветка по контуру допустима только как временный выключатель с датой и задачей на снятие.
- Формат API меняй одновременно у сервера и всех клиентов и воркеров.
- Изменил поведение — в том же коммите обнови документы, по которым работают агенты (база проекта, страница этапа), и базу знаний
  поддержки, если она есть и поведение видит пользователь.
