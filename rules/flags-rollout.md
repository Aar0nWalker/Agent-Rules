# Флаги, стенд и прод

Адреса стендов и команды выката — в `project.md`.

- Новое поведение, способное дать регрессию, выкатывается за флагом, по умолчанию выключенным. Включи на тестовом стенде и докажи
  прогоном. После доказательства переведи в постоянный код и сними флаг вместе со старой веткой.
- Флаг заводится вместе с задачей на его снятие.
- Включён на стенде — ещё не доказан. Доказан: прогон «до/после», соседний путь цел, запись о результате есть.
- Прод только по явной команде владельца проекта. В отчётах не предлагай выкат на прод.
- Прод и стенд исполняют один код. Ветка по контуру допустима только как временный выключатель с датой и задачей на снятие.
- Формат API меняй одновременно у сервера и всех клиентов и воркеров.
- Изменил поведение — в том же коммите обнови документы, по которым работают агенты (база проекта, страница этапа), и базу знаний
  поддержки, если она есть и поведение видит пользователь.
