# /test - прогон тестировщика-человека

Запускается командой `/test <что проверить>`. Сама команда считается разрешением на временные mock-e2e этого прогона.

1. Сформулировать задание продуктовыми словами: что тестить, какой путь пользователя.
   Полигон по умолчанию - тестовый стенд, живой браузер, никогда не прод;
   действия, недоступные на стенде (оплата, платные вызовы), - в mock-e2e.
   Креды для входа тестировщик получает только из `project.md` или задания владельца проекта.
   Задание НЕ содержит кода, диффов и имён файлов - тестировщик смотрит как пользователь.
   Команда не заменяет сценарные mock-e2e спеки проекта.
2. Запустить агента `qa-tester` (Agent tool, subagent_type `qa-tester`) с этим заданием.
   Один прогон - один агент; несколько независимых зон - до 3 агентов параллельно.
3. Отчёт агента передать владельцу проекта кратко: сломано / смущает / ок, со ссылками на скрины.
   Найденные баги не чинить молча - назвать и спросить приоритет, если их больше одного;
   дальше по `rules/root-cause.md`.
