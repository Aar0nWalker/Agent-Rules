# Агентные правила

@project.md

**Роли.** Владелец проекта — человек, который принимает решения. Главная сессия — чат, который режет работу, раздаёт её агентам и сливает результат. Работаешь один: ты владелец, а ревью всё равно делает свежий агент, а не автор.

Правила из `.claude/rules/` действуют всегда. Скиллы загружай по задаче, агентов выбирай по `.claude/rules/agents-cost.md`.
Пути вида `rules/…` и `templates/…` в правилах считаются от `.claude/`.
Страницы этапов — `docs/stages/`, журнал классов багов — `docs/bugs/`, долгие задачи — `docs/plans/`. Другая папка, указанная в `project.md`, важнее.
