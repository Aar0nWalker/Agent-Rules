# Репозиторий агентных правил

Это не продукт, а набор правил для установки в другие проекты. Попросили внедрить правила: прочитай `README.md`, раздел «Инструкция для агента», и работай в проекте, куда их ставят, а не здесь.

При правке самого набора: правила остаются универсальными, всё проектное живёт только в `templates/project.md`.
